# Data Notes

The thesis used 200,020 human vital-sign records. The raw dataset is not uploaded publicly because it contains record identifiers and exact timestamps.

## Public Sample

`public_sample_human_vitals.csv` is a small public-safe sample prepared for repository review. It removes direct patient IDs and exact timestamps, and is intended only to show the data structure used by the modelling workflow.

## Full Dataset

The full dataset should be used locally only unless public-sharing permission and privacy suitability are confirmed.
