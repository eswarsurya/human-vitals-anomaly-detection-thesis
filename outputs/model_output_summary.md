# Model Output Summary

This file gives a public view of the thesis output without exposing the full raw dataset.

## Project Output

The thesis workflow detects unusual human vital sign records using unsupervised anomaly detection. The key output is a set of flagged records, visual summaries, and SHAP based explanations showing which variables influenced the anomaly decision.

## Main Evidence

Dataset scale is 200020 vital sign records. The modelling approach is Isolation Forest. The explainability approach is SHAP values. The output includes anomaly flags, anomaly drivers, and visual model review.

## Interpretation

The project focuses on trust and explainability. Instead of only producing a model score, the work explains why a record appears unusual, making the output easier to review and discuss.
