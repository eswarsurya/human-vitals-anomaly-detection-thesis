# Project Evidence

This folder collects public-safe evidence for the Human Vitals Anomaly Detection thesis project.

## What This Evidence Shows

The project was built around a 200020-record human vital-sign dataset and focused on anomaly detection, explainable AI, and clear model interpretation.

## Current Evidence Files

notebook_walkthrough.md explains the notebook workflow and modelling stages.
report_summary.md summarises the report and presentation content.
outputs/model_output_summary.md summarises the expected model output and interpretation.

## Public Sharing Position

The full raw dataset is not uploaded here until privacy and sharing suitability are confirmed. Public review should use the summaries, workflow notes, and safe sample data.
