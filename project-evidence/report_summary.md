# Thesis Report Summary

This file summarises the public-facing report and presentation content for the Human Vitals Anomaly Detection thesis project.

## Project Purpose

The thesis explores how anomaly detection can identify unusual human vital-sign records and how explainable AI can make those results easier to review.

## Methodology

The project uses data preparation, exploratory analysis, Isolation Forest modelling, SHAP explainability, and visual interpretation of anomaly drivers.

## Main Contribution

The main contribution is not only detecting anomalies, but also explaining why records are flagged. This makes the output more useful for review, communication, and trust.

## Report Structure

The full report covers project background, data preparation, model selection, explainability approach, results, limitations, and future improvements.
